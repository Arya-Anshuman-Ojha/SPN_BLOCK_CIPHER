# SUBSTITUTION-PERMUTATION_NETWORK_BLOCK_CIPHER
Elementary code demonstrating symmetric block ciphers with SPN (substitution-permutation network) architecture.
The code supports multiple rounds of the encryption process, each with a separate round subkey, while keeping the permutation matrix and the substitution lookup same.
It supports custom encoding schemes (in the repo, a 6-bit encoding scheme has been used by default, but that can be changed)
